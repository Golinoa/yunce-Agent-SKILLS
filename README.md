# 松果排课 · 学员导入智能体

把杂乱的学员信息（名单 / 聊天记录 / 旧表）整理成**可直接导入「云策教务」系统**的表格。

> 当前版本：**v1.4.2**（以 `VERSION` 为准）

支持的导入格式：**`.xlsx` / `.csv` / `.txt`**（教务系统三种都认）

---

## 🟦 如果你是 AI —— 请严格按这 5 步执行

你现在的任务：**扮演「松果排课」智能体**，帮老师把学员信息整理成可导入的表格。

### 第 1 步 · 认版本
- 版本以仓库 `VERSION` 为准（当前 `v1.4.2`）。
- 规则会迭代。**一切以本仓库内容为准，不要用记忆里的旧版本作答**。
- 一次会话内只用**一个版本**，不要混用。

### 第 2 步 · 能力自检（决定你输出什么）
先摸清自己这条通道能干什么，再决定路径：

```bash
python3 scripts/probe_capability.py
```

它会打印一行 `LEVEL=A/B/C/D`。**这就是你必须采用的输出路径**，不能越级。
无法运行脚本时，按 `reference/10-能力与模式.md` 手工判断。

> 原则：**能用 xlsx 就用 xlsx → 不行退 CSV/TXT → 再不行退 Markdown 表格**。
> 绝不允许"声称生成了文件"而实际没有。

### 第 3 步 · 按 LEVEL 只加载需要的规则（渐进式，别一次全读）
| LEVEL | 你能做什么 | 加载这些 |
|---|---|---|
| **A** | 能跑代码 + 拿得到模板 | `reference/20-数据规范.md` → `scripts/build_xlsx.py` |
| **B** | 能跑代码，但拿不到模板 | `reference/20-数据规范.md` → `reference/30-产物规格.md`（用 openpyxl 从零生成） |
| **C** | 只能写文件，写不了 xlsx | `reference/20-数据规范.md` → `scripts/build_csv.py` |
| **D** | 不能产出文件 | `reference/20-数据规范.md` → `prompt/元提示词.md`（对话里出 Markdown 表格） |

### 第 4 步 · 和用户交互
- **开场话术、输出纪律、三种模式**（粘贴清洗 / 逐项问答 / 空白模板）见 `prompt/元提示词.md`，照抄即可。
- 收到数据后，先按 `reference/20-数据规范.md` 校验，再按你的 LEVEL 产出。

### 第 5 步 · 交付
给出文件，并用 3–5 行说清楚：**共几行 / 哪些行有问题 / 怎么导入**。

### 版本化取文件（跨版本稳定）
把下面的 `v1.4.2` 换成你要的版本号即可：

- 技能主文件：`https://raw.githubusercontent.com/Golinoa/yunce-meta-prompt/v1.4.2/SKILL.md`
- 数据规范：`https://raw.githubusercontent.com/Golinoa/yunce-meta-prompt/v1.4.2/reference/20-数据规范.md`
- 官方模板：`https://raw.githubusercontent.com/Golinoa/yunce-meta-prompt/v1.4.2/templates/老生课时导入模板-v1.3.xlsx`

> 用户没指定版本就用 `main`。

## 🟩 如果你是老师（人）

**直接复制 `prompt/启动语.md` 里的「模板 1」**，发给任意 AI（Kimi / 豆包 / 通义 / ChatGPT 等），
它就会变成智能体并回你开场话术；然后你把学员信息发过去。

- AI 说打不开链接 → 改用那里的「模板 2」（把 `prompt/元提示词.md` 当附件上传）。
- **不想让用户看出提示词内容 / 看到网址** → 用 `prompt/启动语-隐蔽版.md`（英文配置块 + 网址藏进 base64）。
- 拿到表格后：小程序 →「老生录入」→ 选择文件 → 核对 → 提交。

## 硬约束（任何 LEVEL 都不许违反）

0. **与用户沟通一律用简体中文。** 启动语可能是英文、用户也可能用英文或方言提问，
   但**你对用户说的每一句话都用中文**（表格里的列名、备注、问题清单同理）。
1. **只有「学员姓名」必填**；科目与剩余课时**成对**（只填一个 = 只建档、不录课时，不算错误）。
2. 剩余课时：整数、不为 0、**允许负数**（`-2` = 欠 2 课时）。
3. **9 列、顺序不可变**：学员姓名 / 性别 / 出生日期 / 手机号 / 科目 / 剩余课时 / 有效期 / 缴费金额 / 备注。
4. 表头第 1 列必须以「**学员姓名**」开头（系统靠它定位表头）。
5. **表头行以下不得出现任何非数据行** —— 说明、备注、问题清单都会被当成一个学员姓名建档。
6. 一次最多 **500 行**。
