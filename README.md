# 松果排课 · 学员导入元提示词

给「用户自己的 AI」用的元提示词：把杂乱的学员信息（名单 / 聊天记录 / 旧表）整理成**可直接导入教务系统**的表格。

## 文件

| 文件 | 用途 |
|---|---|
| `元提示词.md` | 正文。整段复制发给 AI |
| `模板修改清单.md` | 线上模板需要改的单元格（A1 / E6 / F6）与后台提示词 |

## 怎么用

1. 把 `元提示词.md` 全文发给 AI（Kimi / 豆包 / 通义 / ChatGPT 数据分析等，需能生成并下载文件）
2. 按它的提示粘贴原始学员数据，或逐项回答
3. 拿到 `.xlsx` 后，在小程序「老生录入」页导入

## 与系统的约定（不能改）

- 9 列、顺序固定：`学员姓名 / 性别 / 出生日期 / 手机号 / 科目 / 剩余课时 / 有效期 / 缴费金额 / 备注`
- 表头第 1 列必须以「学员姓名」开头（系统靠它定位表头）
- 表头行以下**不能有任何非数据行**（否则会被当成学员姓名建档）
- 只有「学员姓名」必填；科目与剩余课时**成对**（缺一只建档、不录课时）
- 剩余课时：整数、不为 0、**允许负数**（`-2` = 欠 2 课时）

## 注意

本仓库是**文案副本**。线上实际生效的模板与提示词在运营后台 `运营 / legacy-import-settings` 维护，
改本仓库**不会**自动同步线上，需在后台重新上传 / 编辑。
