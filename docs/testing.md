# 测试用的假授权地址

> 只用于**没有后端**时的链路测试。**真值绝不进本仓库**（本仓库是公开的）。

```text
https://assist-import.invalid/assist-import/gate/TESTONLY-0001
```

## 它是干什么的

`.invalid` 是 **RFC 2606 保留域，规定上永不解析** ⇒ 任何 AI 去调它都**必然失败** ⇒
**必然走「发不出请求」分支**。用它验证两件事：

- AI 会不会**诚实承认**发不出请求（**不会**假装"已经送进系统了"）；
- 会不会**只给一条路**（整理成表格），而不是继续问你要不要直连。

刻意不用真实域名 —— 免得测试流量打到线上、污染生产日志。

## 怎么用

把这段地址交给 AI（或写进测试提示词），观察它是否按上面那样降级。

## 想造其它分支

| 想测什么 | 怎么做 |
|---|---|
| 服务端拒绝（凭证无效/过期） | 换成真实域名 + 无效 token |
| 提示词里根本没有授权地址 | 把地址整行删掉 ⇒ 应走「没有直连权限」分支 |
| 握手成功（需要后端） | 起后端并打通网络，用 `/assist-import/prompt` 生成的真实地址 |

---

## 为什么它不在交互元提示词里

交互元提示词（`assets/interactive-meta-prompt.md`）是**给老师用的产物**，只保留两样：
仓库线索 + 一次性授权地址（**占位符**，真值由后端在「复制」时注入）。

测试用的假地址属于**开发/运维信息**，放这里即可，不必进模板 ——
避免以后有人把它当成真值发出去。
