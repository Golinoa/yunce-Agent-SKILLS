# 测试用地址与授权码

> 只用于**没有后端**时的链路测试。**真值绝不进本仓库**（本仓库是公开的）。

## 当前链路怎么走（v2.6.0）

```text
交互提示词里只有两样：
   ① 仓库名（Golinoa/yunce-meta-prompt）
   ② 一个授权码（如 TESTONLY-0001）
                     ↓
智能体：去了解仓库 → 进入角色 → 从仓库读到 base → 自己拼地址 → 访问
                     ↓
握手地址 = {base}/assist-import/gate/{code}
             ↑                         ↑
      固定在本仓库                交互提示词里传的码
```

## 测试用的值

| 项 | 值 | 放在哪 |
|---|---|---|
| `base`（接口基址） | `https://assist-import.invalid` | **仓库里** —— `SKILL.md` 的 `## Endpoint` 节 |
| `code`（授权码） | `TESTONLY-0001` | **交互提示词里**传 |
| 拼出来的握手地址 | `https://assist-import.invalid/assist-import/gate/TESTONLY-0001` | 智能体**自己拼** |

`.invalid` 是 **RFC 2606 保留域，规定上永不解析** ⇒ 任何 AI 去调它都**必然失败** ⇒
**必然走「发不出请求」分支**。刻意不用真实域名，免得测试流量打到线上、污染生产日志。

## 用它验证什么

1. AI 会不会**自己拼对**这个地址（`base` 从仓库读、`code` 从提示词读）；
2. 连不上后会不会**诚实承认**发不出请求（**不会**假装"已经送进系统了"）；
3. 会不会**只给一条路**（整理成表格），而不是继续问你要不要直连。

## 想造其它分支

| 想测什么 | 怎么做 |
|---|---|
| 服务端拒绝（码无效/过期/已用） | 换真实 `base` + 无效或过期的 `code` |
| 提示词里根本没有授权码 | 删掉 `One-time authorization code:` 那一行 ⇒ 应走「没有直连权限」分支 |
| 握手成功（需要后端） | 起后端并把 `SKILL.md` 里的 `base` 改成可达地址，用后端生成的真实码 |
| 提示词里没有仓库线索 | 删掉前两行 ⇒ AI 应该只会走表格路线 |

---

## 为什么 baseurl 在仓库里，而不是在提示词里

2026-10-14 的决定：**交互提示词里要彻底不出现域名 / URL** —— 越干净，越不像"执行远程指令"。
所以 `base` 固定进仓库，提示词只传一个**人类可读的短码**。

**代价如实记录：API 基址对公开可见。**

这不构成权限漏洞 —— 真正的权限点是**老师在小程序里点授权 + 服务端发短码**；
光有地址和码，最多建出一个**待授权**会话，没有老师确认，什么都进不了库。
