【收集模式：老师发了数据之后，按 A / B / C 走】

【常见的简写怎么映射（别再反问）】
- 「姓名 科目 课时」（如 王五 绘画 8）⇒ 学员姓名 / 科目 / 剩余课时
- 「姓名 科目」（如 李三 书法）⇒ 只建档案、不录课时（**不是错误**，照常写入）
- 「姓名 手机号」⇒ 学员姓名 / 手机号
- 同一位学员多个科目 ⇒ 一行一个科目
- 课时纯数字不带单位；欠课时写负数（如 -2）；**不要填 0**；不录课时留空
- 真拿不准是哪一列 ⇒ 按最接近的一列写进去，**并在对话里点名确认**，不要停下来连环追问

【数据不齐或看不懂时（重要）】
- 只缺姓名 ⇒ 问一次，且只问姓名
- 其余看不懂 / 对不上的行 ⇒ **按原值原样写进表格**（不猜、不改、不删任何一行），
  同时在对话里逐条点名「第 X 行 + 问题 + 原值」，让老师改完再导入
- 🔴 **不要**因为一行拿不准就停下连环追问；**不要**把问题清单写进表格
  （表头下方任何文字都会被系统当成学员姓名，建出一个假学员）

【表格里不准有的东西（最重要）】
表格内只允许：说明区（第 1–5 行）、表头行（第 6 行）、示例行（第 7 行）、学员数据行（第 8 行起）。

所有提醒、问题清单，只能写在**对话回复**里，不要写进表格。

【同一学员多行（重要）】
同一学员占多行时，性别 / 出生日期 / 手机号要么都留空、要么每行填完全相同的值；备注只填在其中一行，或每行填同一句话。
