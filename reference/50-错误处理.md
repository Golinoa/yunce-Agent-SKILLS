# 错误处理

> 任何一步出问题，先查这份。**核心原则：`retryable=false` 一律不重试，并且绝不对老师说"已经成功了"。**

---

## 一、最坏的情况

> **报错不可怕，可怕的是老师以为"导入成功了"。**
> 所以：**只要没走到第 6 步、老师没在小程序确认，就绝不能对老师说"已经导入完成"。**

---

## 二、`retryable` 这条线怎么用

服务端出错都会返回：

```json
{ "code": "XXX", "message": "给用户看的人话", "retryable": false }
```

| `retryable` | 你该做什么 |
|---|---|
| **false** | **立即停止，不许重试**，按下面的表照话术告诉老师 |
| **true** | 可以**退避重试，最多 3 次**（间隔 2s → 5s → 10s）；3 次都失败就当 false 处理 |

---

## 三、错误码 → 你该怎么说

| code | 含义 | 你的动作 | 对老师说的话 |
|---|---|---|---|
| `FEATURE_DISABLED` | 直接写入被临时关停 | **停止**，转「整理成表格」 | 「这边暂时没法直接送进系统了，不过我可以帮你整理成表格，你拿去小程序上传就行」 |
| `TOKEN_MISSING` | 启动语里**没带凭证**（很可能是从公开仓库直接复制的说明） | **停止**，别硬试 | 「这份说明里没有绑定你的账号。麻烦你回小程序**重新复制一份**发我；不方便的话，我现在直接帮你**整理成表格**也行」 |
| `TOKEN_EXPIRED` | 凭证**超 1 小时未使用**（只在开场握手时会出现） | **停止** | 「这份说明拖太久了。麻烦你回小程序**重新复制一份**发我；或者我直接帮你**整理成表格**」 |
| `TOKEN_CONSUMED` | 凭证**已经被用过了**（一份只能用一次，转发给别人也无效） | **停止** | 「这份说明已经用过了。麻烦你回小程序**重新复制一份**；不想折腾的话，我现在帮你**整理成表格**」 |
| `BATCH_CONFLICT` | 老师还有一批没确认 | **停止**，不开新批 | 「你还有一批名单没确认，先去小程序把那一批处理完，我再帮你弄新的」 |
| `COOLDOWN` | 申请太频繁，正在冷却 | **停止** | 「刚才连续操作了几次，需要等大概 {N} 分钟再试；或者我现在先帮你整理成表格」 |
| `QUOTA_EXCEEDED` | 今天申请次数用完了 | **停止** | 「今天申请的次数到上限了，明天再试；现在我可以帮你整理成表格」 |
| `AUTH_CODE_EXPIRED` | 短码过期（超 5 分钟） | 不重试，**重新走一次授权** | 「短码过期了，麻烦你再打开小程序刷新一下首页、重新点一次授权，把新的短码发我」 |
| `AUTH_CONSUMED` | 短码已经被用过了 | 不重试，**重新授权** | 「刚才那串码用过了，需要再授权一次：打开小程序刷新首页，把新的短码发我」 |
| `CODE_MISMATCH` | 短码对不上 | 不重试 | 「短码好像没对，麻烦你回小程序页面再看一眼，整串发我（8 位）」 |
| `SESSION_REVOKED` | 这次授权已被撤回 | 不重试，**重新授权** | 「这次授权被撤回了，需要重新走一遍：打开小程序刷新首页 → 授权 → 把短码发我」 |
| `SESSION_NOT_AUTHORIZED` | 老师还没完成授权 | **等老师**，不要自己重试 | 「还没看到你的授权，麻烦打开小程序刷新一下首页，弹出来的框点一下授权」 |
| `IDENTITY_MISMATCH` | 授权的人和名单归属对不上 | **停止** | 「授权用的账号和这批名单对不上，我没法继续。麻烦你在小程序里用本人的账号再授权一次」 |
| `NOT_OWNER` | 不是这批的发起人 | **停止** | 「这批名单不是当前账号建的，我看不到。请用当初发起的那台设备/账号操作」 |
| `BATCH_TOO_LARGE` | 超过 500 行 | 不重试 | 「一次最多 500 人，我们分两批发吧。先发前 500 个？」 |
| `RATE_LIMITED` | 请求太频繁 | **退避重试 ≤3 次** | 重试期间不用打扰老师；3 次都失败再说「网有点忙，稍等我再试一下」 |
| `SERVER_BUSY` | 服务端忙 | **退避重试 ≤3 次** | 同上 |

**撤回相关**（老师在小程序里操作时才会遇到，你只需解释）：
| code | 对老师说的话 |
|---|---|
| `WITHDRAW_WINDOW_CLOSED` | 「超过 24 小时了，撤回不了。如果确实导错了，需要在小程序里把对应的期初卡删掉再重新上传」 |
| `WITHDRAW_NOT_ALLOWED` | 「这批学员已经有后续记录（比如已经点过名/消过课），不能整批撤回了。需要手动处理有问题的几条」 |

## 四、网络层失败（还不算"服务端拒绝"）

| 现象 | 含义 | 处理 |
|---|---|---|
| 命令跑不起来 / 没有 `curl` / 沙箱禁止联网 | **`NET=no`** | 立刻放弃"直接写入"，改走**整理成表格**，并照 `prompt/开场与选路.md` 的话术推荐换 AI |
| 请求发出去了，但**一直没返回 / 超时** | 不确定成功没有 | 写隔离区那一步**可以安全重试**（幂等）；**换钥匙那一步不要重试**，让老师重新授权 |
| 返回了，但不是 JSON | 可能是网关错误 | 当作 `SERVER_BUSY` 处理（退避重试 ≤3 次） |

---

## 五、绝对禁止

1. ❌ 把 `retryable=false` 的错误当成"网络抖动"去重试。
2. ❌ 失败之后对老师说"已经导入好了 / 已经放进去了"。
3. ❌ 已经出过错还继续往下走（比如换钥匙失败还硬去写隔离区）。
4. ❌ 编造一个"错误原因"来跟自己圆场 —— **照实说，并把原始报错留着**。
