# 数据规范（唯一真源）

> 这份文件是**校验与清洗口径的唯一真源**。README / SKILL / 元提示词若与本文冲突，**以本文为准**。
> 对应系统实现：`yunce-backend/src/legacy-hours-import/`。

## 一、9 列（顺序不可变）

| # | 列名 | 必填 | 说明 |
|---|---|---|---|
| 1 | 学员姓名 | ✅ | 唯一必填项。≤ 50 字 |
| 2 | 性别 | | 只填「男」或「女」；不确定留空 |
| 3 | 出生日期 | | `YYYY-MM-DD`；只有年份就补 `01-01` |
| 4 | 手机号 | | 11 位大陆手机号；没有留空 |
| 5 | 科目 | | 如「钢琴」「书法」 |
| 6 | 剩余课时 | | 整数；**可为负数**；见下 |
| 7 | 有效期 | | `YYYY-MM-DD`；留空 = 永久 |
| 8 | 缴费金额 | | 单位「元」，非负数、最多两位小数 |
| 9 | 备注 | | 自由文本，≤ 191 字 |

**同一个姓名 = 同一个学员**。一人多科目就写多行、姓名重复出现（正常）。

## 二、必填与"成对"规则（最容易搞错）

- **只有「学员姓名」必填**。其余 8 列全部选填。
- **科目 + 剩余课时 是成对的**：
  - 两列都填 → 正常挂课时卡；
  - **只填其中一列 → 这一行只建档案、不录课时，而且不算错误**。
- 所以：**不要把"科目/课时必填"写进任何提示词或说明**（线上旧模板就是这么写的，是过期口径）。

## 三、剩余课时

- 纯数字，不要写单位（「还剩 12 节课」→ `12`）。
- **允许负数**：`-2` = 欠 2 课时（欠课记在卡的负数上）。
- **不允许 0**：0 课时的卡在界面上看不出来，没意义 → 留空即可。
- 只填课时不填科目（或反之）→ 该行只建档。

## 四、同一学员多行时的"一致性"（会整组判错）

| 项目 | 规则 | 不一致的后果 |
|---|---|---|
| 性别 / 出生日期 / 手机号 | 要么都留空，要么每行**完全相同** | 整组判错 |
| 备注 | **只填在其中一行**，或每行填**同一句话** | 整组判错 |

> AI 最容易在这两条翻车：给同一学员的两行各写了一个不同的手机号，或备注各写各的 ⇒ 老师导入时整组失败还找不到原因。

## 五、格式与长度上限

| 项 | 规则 | 系统行为 |
|---|---|---|
| 姓名 | ≤ 50 字 | 超了报错 |
| 备注 | ≤ 191 字 | 超了报错（且与系统已有备注合计也 ≤ 191） |
| 有效期 | `YYYY-MM-DD` | 填了就必须合规，否则报错 |
| 缴费金额 | 非负数、≤ 两位小数 | 不合规报错 |
| 出生日期 / 性别 / 手机号 | **不做格式拦截** | 认不出来 = 当没填（宽松收敛） |
| 单批行数 | **≤ 500 行** | 超了报「单批最多 500 行」 |

> 注意加粗那行：这三个字段系统不会拦，所以**在 AI 侧就规范好**更划算（本来也是提示词要求的）。

## 六、清洗与"问题行"处理口径

1. **不猜、不改、不删**：不合规或看不懂的行，**按原值原样写入表格**。
2. 同时在**对话回复**里用清单逐条点名：`原始数据第 X 行 + 问题 + 原值`。
3. 让老师改完再导入。

> 这与"歧义行绝不猜着放行"的产品口径一致：宁可让老师看见问题，也不要静默改数或静默丢行。

## 七、🔴 红线：表头行以下不得有任何非数据行

系统解析时**只跳过三种行**：

1. 空行（第 1 列没内容）
2. 第 1 列以「**示例**」开头
3. 第 1 列内容正好是「**必填**」

⇒ 其余任何非空文字都会被当成**学员姓名**建档。所以在表格里写：

- `备注：第3行手机号疑似有误` ❌ → 会新建一个叫"备注：第3行手机号疑似有误"的学员
- `说明：以上共 12 条` ❌
- `合计` ❌

**所有说明、清单、提醒，只能写在对话回复里。**

## 八、列里出现的内容要不要清洗

| 情况 | 处理 |
|---|---|
| 姓名前后/中间多余空格 | 去掉（姓名内部空格也去掉） |
| 「还剩 12 节课」「12 课时」 | 取数字 `12` |
| 日期写成 `2015/1/1`、`2015年1月1日` | 统一成 `2015-01-01` |
| 性别写「男孩子」「女孩」 | 归一到「男」「女」；实在判不准 → 留空 |
| 手机号中间有空格/横线 | 去掉非数字字符；位数不对 → 留空，并在清单里点名 |
| 原始数据里没有的选填项 | **留空，绝不编造**（尤其缴费金额） |
