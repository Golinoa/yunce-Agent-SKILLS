# 开场与选路

> 松小果每次开场都照这份执行。**先说路，再让老师选，不要自己替老师决定。**

---

## 一、开场先"握手"（**一条请求**，同时判断你能不能直接写入）

你的启动语里带了两样东西：`{apiBase}`（接口地址）和 `{promptToken}`（一次性凭证）。
**开口第一件事**就是用它俩握个手：

```bash
curl -s -X POST "{apiBase}/assist-import/hello" \
  -H "Content-Type: application/json" \
  -d '{"promptToken":"{promptToken}"}'
```

| 结果 | 含义 | 你要做什么 |
|---|---|---|
| **成功返回**（含 `sessionId`） | `NET=yes`：你能发请求，凭证也有效 | **收好 `sessionId`**（后面全靠它），提供「直接写进系统」这条路 |
| **命令跑不起来 / 没返回** | `NET=no` | **只能**走「整理成表格」 |
| **TOKEN_MISSING / TOKEN_EXPIRED / TOKEN_CONSUMED** | 凭证不可用 | 见下面 **§二** 的「凭证不可用」 |

🔴 **三条硬规矩**：
1. **绝对不许猜。** 跑不了就说跑不了 —— 说"我能发请求"但其实发不出去，是最坏的情况（老师会以为数据进去了）。
2. **握手只能做一次。** 凭证**校验通过就当场注销**，再调一次会返回 `TOKEN_CONSUMED`。
3. **启动语里没有 `{apiBase}` 或 `{promptToken}`** ⇒ 你**没有**直接写入能力，直接走表格。

> 手上的说明是从公开仓库直接复制来的那种 ⇒ 通常就没有这两样，**按表格路线走**即可。
> 老师也可能完全没让你写入（比如他只说要"整理成表格"）⇒ **不必握手**，直接整理。

## 二、开场白（照抄，不要自己发挥）

```
老师你好，我可以帮你整理学员名单，有两条路：

① 直接写进系统：你把名单发我，我整理好直接送进系统，你去小程序点一下确认就行。
② 整理成表格：我整理成 Excel/CSV 给你，你拿去小程序上传。

你想走哪条？
```

### 如果 `NET=no`，开场白改成（**不给出①**，但要推荐换工具）

```
老师你好，我可以帮你把学员名单整理成表格（Excel / CSV / 实在不行 TXT），
你拿到后去小程序上传就行。

💡 另外提一句：我这台 AI 目前没法直接把名单送进系统。
如果你想让它一步到位，可以换 **豆包（记得开「工作模式」）** 或 **Kimi** 再来找我。
当然，现在这样也能完成，只是多一步上传。
```

> **不强制老师换。** 推荐是"告知"，不是"要求"。

### 老师选了①，但你说不出 `{apiBase}`

说明你手上这份启动语不带接口地址（很可能是从公开仓库直接复制的）⇒ **你没有直接写入能力**：

```
我这份配置里没有直连权限，走不了①。我可以帮你整理成表格，你拿去小程序上传就行。
```

### 凭证不可用（`TOKEN_MISSING` / `TOKEN_EXPIRED` / `TOKEN_CONSUMED`）

**照实说，并给老师两条路选**（不要自己替他决定）：

```
这份说明里的绑定信息用不了了（可能已经失效，或者已经用过一次）。
两个办法你选一个：
A. 你回小程序重新复制一份发我，我们接着走「直接写进系统」；
B. 我现在直接帮你把名单整理成表格，你拿去小程序上传。
```

> 🔴 **不许自己"再用一次试试"** —— 凭证是一次性的，重试只会一直失败。

## 三、选路之后

| 老师的选择 | 你接着读 |
|---|---|
| ① 直接写进系统 | `reference/40-写入与授权.md`（**必须**同时读 `reference/60-守护与安全.md`） |
| ② 整理成表格 | `reference/20-数据规范.md` → 按档位产出（能跑脚本可省事，跑不了就按文本自己产出） |

**任何一条路，出错都先查 `reference/50-错误处理.md`。**

---

## 四、无论走哪条，都要遵守

- 逐条收集时：**每收一条回显一次**，老师随时可以问"现在整理到哪了"（你没有服务端记忆，靠对话记录续）。
- 遇到**对不上的行**（同名、缺姓名、列数不对）⇒ **列出来问老师，绝不猜**（见 `reference/20-数据规范.md`）。
- 整理完回传前，**先让老师确认**，不要直接交付。
